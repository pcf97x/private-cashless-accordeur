1. Introduction

L'Accordeur est une plateforme de gestion pour le Pole Associatif de Guyane, un espace de 1 600 m2 situe a Cayenne. La plateforme permet de :

  • Gerer le pointage des visiteurs et residents via WeezAccess (Weezevent)
  • Reserver des salles en ligne avec paiement securise (Stripe)
  • Gerer les contacts et l'historique des visites
  • Administrer les espaces, creneaux, tarifs et options
  • Presenter l'ecosysteme des associations residentes

2. Acces a la plateforme

Se connecter

  1. Rendez-vous sur https://laccordeur973.fr/login
  2. Saisissez votre email et votre mot de passe
  3. Cliquez sur Se connecter

Roles utilisateurs

RoleAcces
AdminAcces complet : salles, tarifs, utilisateurs, reservations, pointage, ecosysteme
ManagerGestion des reservations, pointage, contacts, salles
AccueilPointage, contacts, consultation des reservations

3. Tableau de bord

Apres connexion, le tableau de bord affiche en un coup d'oeil :

  • Nombre de personnes presentes actuellement dans le batiment
  • Entrees du jour (nombre de pointages d'entree)
  • Nombre total de contacts enregistres
  • Derniers pointages avec le statut (present, sorti, en attente)

Le menu lateral gauche permet d'acceder rapidement a toutes les fonctionnalites.

4. Pointage et Acces visiteurs

4.1 Comment fonctionne le pointage

Le pointage fonctionne avec WeezAccess (application Weezevent) sur un terminal a l'entree :

  1. Le visiteur ou resident presente son QR code / code-barres Weezevent
  2. Le terminal WeezAccess scanne le code
  3. La synchronisation automatique (chaque minute) remonte le scan dans la plateforme
  4. Le premier scan du jour enregistre l'entree
  5. Chaque scan suivant met a jour l'heure de sortie
Fermeture automatique : A 19h00, tous les pointages sans sortie sont fermes automatiquement.

4.2 Page de pointage

La page affiche les statistiques en haut (total, presents, en attente, sortis), le formulaire de scan, puis le tableau des pointages du jour.

4.3 Scanner un code manuellement

Si le terminal WeezAccess n'est pas disponible :

  1. Allez sur Pointage dans le menu
  2. Saisissez le code dans le champ "Scannez ou saisissez le code QR / Weezevent..."
  3. Appuyez sur Entree ou cliquez sur Pointer
  4. Un message de confirmation s'affiche
Douchette USB : Branchez la douchette, scannez le code-barres. Le formulaire se soumet automatiquement.

4.4 Creer un Pass Visiteur

  1. Allez sur Nouvel acces dans le menu (ou https://laccordeur973.fr/acces)
  2. Remplissez le formulaire : prenom, nom, email, motif de visite
  3. Cliquez sur Enregistrer
  4. Un QR code est genere et envoye par email au visiteur
  5. Le visiteur presente ce QR code au terminal WeezAccess

4.5 Statuts de pointage

StatutSignification
En attenteLe pass est cree mais aucun scan n'a ete effectue
PresentLe visiteur est entre (scan d'entree, pas encore de sortie)
SortiLe visiteur est sorti (scan de sortie enregistre)

5. Gestion des contacts

La page Contacts affiche tous les contacts enregistres avec leur nombre de visites et dernier QR code.

Cliquez sur un contact pour voir ses informations completes et l'historique de toutes ses visites.

6. Reservation de salles (parcours client)

6.1 Choisir une salle

Sur https://laccordeur973.fr/reservation, le client voit les salles disponibles avec photo, capacite, equipements et fourchette de prix.

6.2 Choisir une date et un creneau

  1. Selectionnez une date dans le calendrier (points verts = disponible, rouges = reserve)
  2. Choisissez un creneau parmi ceux affiches a droite
  3. Selectionnez votre profil tarifaire - le prix s'affiche automatiquement
  4. Ajoutez des options si souhaitees (petit dejeuner, repas...) avec quantite

6.3 Coordonnees et paiement

  1. Remplissez vos coordonnees : nom, email, telephone
  2. Cliquez sur Reserver & Payer
  3. Vous etes redirige vers Stripe pour le paiement securise
  4. Apres paiement, un email de confirmation est envoye

6.4 Le planning public

Le planning (/planning) affiche les reservations de toutes les salles sur un calendrier interactif.

7. Administration des reservations

La page affiche toutes les reservations avec client, salle, date, prix et statut.

Actions disponibles

En cliquant sur une reservation :

  • Renvoyer l'email de confirmation au client
  • Annuler et rembourser la reservation (le remboursement Stripe est automatique)

8. Gestion des salles

Creer une salle

  1. Cliquez sur Nouvelle salle
  2. Remplissez : nom, description, photo, capacite, surface, adresse, equipements
  3. Cochez Active pour la rendre disponible a la reservation
  4. Cliquez sur Creer la salle
Equipements : Separez-les par des virgules (ex: Videoprojecteur, Wi-Fi, Tableau blanc)

9. Creneaux horaires

Les creneaux definissent les plages de reservation. Exemple :

CreneauHoraires
Matin07h00 - 13h00
Apres-midi13h00 - 19h00
Journee07h00 - 19h00

Allez dans Creneaux pour ajouter, modifier ou desactiver des creneaux.

10. Grille tarifaire

Profils tarifaires

Les profils definissent les types de clients :

Vous pouvez ajouter de nouveaux profils (ex: Resident, Partenaire) depuis Profils tarifaires.

Matrice des tarifs

La page Tarifs permet de definir les prix pour chaque combinaison salle x creneau x profil.

  1. Saisissez les prix dans les champs du tableau
  2. Cliquez sur Enregistrer les tarifs
Important : Si un prix n'est pas defini pour une combinaison, le client ne pourra pas reserver cette combinaison.

11. Options de reservation

Les options sont des extras que le client peut ajouter (petit dejeuner, repas, etc.).

Ajouter une option

  1. Cliquez sur Nouvelle option
  2. Remplissez : nom, description, prix en EUR
  3. Cochez Active pour la proposer lors de la reservation
  4. Cliquez sur Creer l'option

12. Ecosysteme et partenaires

Page publique

La page Ecosysteme presente les associations hebergees dans les bureaux associatifs.

Gerer les partenaires

  1. Cliquez sur Nouveau partenaire
  2. Remplissez : nom, presentation, logo, contact, site web
  3. Cochez Visible sur le site
  4. Cliquez sur Ajouter le partenaire

13. Gestion des utilisateurs

Acces reserve aux administrateurs.

Creer un utilisateur

  1. Allez dans Utilisateurs dans le menu
  2. Cliquez sur Nouvel utilisateur
  3. Remplissez : nom, email, mot de passe
  4. Selectionnez le role (Admin, Manager ou Accueil)
  5. Cliquez sur Creer
